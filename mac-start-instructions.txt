To start Horizon on macOS, double-click start-horizon.command in this folder.

Alternatively, open Terminal, change to this project folder, and run:

  bash start-horizon.command

The first run creates the Python environment and installs the required packages.
The launcher checks that the frontend build exists, opens Horizon in your browser,
and runs the local server. Press Control-C in Terminal to stop it.

If the launcher reports that frontend/dist is missing, build the frontend from
Terminal with:

  cd frontend
  npm install
  npm run build

Then run start-horizon.command again from the project folder.
